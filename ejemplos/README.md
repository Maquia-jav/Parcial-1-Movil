# Ejemplos — Soluciones completas de la guía de ejercicios

Cada archivo resuelve un ejercicio completo de `Ejercicios-CM-01.pdf` de principio a fin
(pantalla principal + pantallas de navegación + lógica). Cópialos y adapta nombres/estilos
según lo que pida tu enunciado exacto en el examen.

| Archivo | Ejercicio | Qué practica |
|---|---|---|
| `Ejercicio1.kt` | 1.1 a 1.5 | Column/Row, imagen sobre TextField, DropdownMenu centrado, botones abajo en Row, márgenes, abrir URL, pasar datos entre pantallas, LazyColumn con arreglo fijo de Strings |
| `Ejercicio2.kt` | 2.1 a 2.3 | Layout responsive (Portrait/Landscape) sin ViewModel, TextField numérico restringido (1-15), navegar mostrando el resultado de un cálculo (factorial) |
| `Ejercicio3.kt` | 3.1 a 3.4 | Proporciones de ancho (70%/30%) con `weight`, margen uniforme, validar rango con Toast+Log, LazyColumn con una sucesión calculada, texto con estilo al seleccionar un ítem |
| `Ejercicio4.kt` | 4.1 a 4.4 | Margen uniforme, imagen circular, TextField/Botón a todo el ancho, validar otro rango, `ListItem` + `HorizontalDivider`, texto con otro estilo al seleccionar |

## Cómo usarlos en el examen

1. Lee el enunciado real y busca cuál de estos 4 se parece más.
2. Copia el archivo completo a tu proyecto.
3. Cambia únicamente lo que el enunciado pida diferente: nombres, colores, rangos, textos.
4. La estructura de navegación (`NavKey`, `NavDisplay`, `entryProvider`) es siempre la misma —
   solo agregas o quitas rutas según cuántas pantallas necesites.
